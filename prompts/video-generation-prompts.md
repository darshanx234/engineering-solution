**Duration**: 4 seconds | **Best For**: Hero Section Background | **Estimated Size**: 8-12MB

```

Lighting: Golden hour lighting, clear sky, professional cinematography
Resolution: 1920x1080, 30fps, professional color grading

Technical specifications:
- Format: MP4 or WebM
- Frame rate: 30fps
- Bitrate: 4-5 Mbps
- Duration: Exactly 4 seconds
- Aspect ratio: 16:9
```

## 📋 How to Use with Gemini

### Step-by-Step Instructions:

1. **Go to Google Gemini**: https://gemini.google.com/
2. **Sign in** with your Google account
3. **Look for "Generate video"** or **"Video generation"** option
4. **Copy the prompt** you want to use from above (e.g., start with Prompt #1)
5. **Paste it** into Gemini's prompt field
6. **Click "Generate"** or **"Create Video"**
7. **Wait** for generation (2-10 minutes depending on complexity)
8. **Download** the generated video as MP4
9. **Save to**: `public/videos/hero-animation.mp4`

## 🔧 Video Conversion (Optional but Recommended)

If you need to convert MP4 to WebM for better compression:

```bash
# Install ffmpeg (free)
# Windows: choco install ffmpeg
# Mac: brew install ffmpeg
# Linux: sudo apt install ffmpeg

# Convert MP4 to WebM
ffmpeg -i hero-animation.mp4 -c:v libvpx-vp9 -crf 30 -c:a libopus hero-animation.webm

# Compress MP4 for web
ffmpeg -i hero-animation.mp4 -c:v libx264 -crf 23 -preset slow -c:a aac -b:a 128k hero-animation-compressed.mp4
```
